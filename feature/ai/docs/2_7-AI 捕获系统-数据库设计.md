# AI 捕获系统数据库设计（SQL PRD V1.0）

---

## 1. 文档定位

* 类型：数据库设计（SQL Schema）
* 层级：Storage Layer（支撑 Card Engine / AI Pipeline / Conversation Engine）
* 数据库类型：推荐 PostgreSQL + JSONB + 向量扩展（pgvector）

---

# 二、设计原则

## 2.1 核心原则

```text
结构化字段 + JSON扩展 + 向量能力
```

---

## 2.2 拆分策略

将 Card 拆为：

```text
cards（核心表）
+
card_content（内容块）
+
card_media（媒体）
+
card_tags（标签）
+
card_entities（实体）
+
card_relations（关系）
```

👉 原因：

* 避免 JSON 过大不可查询
* 支持索引优化
* 支持 AI & Graph 查询

---

# 三、核心表结构

---

# 3.1 cards（核心表）

```sql
CREATE TABLE cards (
    id              UUID PRIMARY KEY,
    user_id         UUID NOT NULL,

    type            VARCHAR(50) NOT NULL,
    title           TEXT NOT NULL,
    summary         TEXT,

    status          VARCHAR(20) DEFAULT 'draft',

    source_kind     VARCHAR(20),
    source_ref      TEXT,

    location_name   TEXT,
    latitude        DOUBLE PRECISION,
    longitude       DOUBLE PRECISION,

    ui              JSONB, -- cover/icon/bg

    created_at      TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMP NOT NULL DEFAULT NOW()
);
```

---

## 设计说明

| 字段       | 说明                  |
|----------|---------------------|
| type     | 对应 Card Type System |
| status   | 对应 State Machine    |
| ui       | 前端展示配置              |
| location | 支持地理搜索              |

---

# 3.2 card_content（内容块）

```sql
CREATE TABLE card_content (
    id          UUID PRIMARY KEY,
    card_id     UUID REFERENCES cards(id) ON DELETE CASCADE,

    content_type VARCHAR(20), -- text/link/code/list/image
    value        JSONB,

    position     INT, -- 排序
    created_at   TIMESTAMP DEFAULT NOW()
);
```

---

## 设计说明

支持：

```text
Block-based Content
```

示例：

```json
{
  "type": "text",
  "value": "昨天在上海吃了一兰拉面"
}
```

---

# 3.3 card_media（媒体）

```sql
CREATE TABLE card_media (
    id          UUID PRIMARY KEY,
    card_id     UUID REFERENCES cards(id) ON DELETE CASCADE,

    media_type  VARCHAR(20), -- image/video/file/audio
    url         TEXT NOT NULL,
    caption     TEXT,

    created_at  TIMESTAMP DEFAULT NOW()
);
```

---

# 3.4 tags（标签字典表）

```sql
CREATE TABLE tags (
    id          UUID PRIMARY KEY,
    name        VARCHAR(100) UNIQUE NOT NULL,
    created_at  TIMESTAMP DEFAULT NOW()
);
```

---

# 3.5 card_tags（卡片标签）

```sql
CREATE TABLE card_tags (
    card_id UUID REFERENCES cards(id) ON DELETE CASCADE,
    tag_id  UUID REFERENCES tags(id) ON DELETE CASCADE,

    PRIMARY KEY (card_id, tag_id)
);
```

---

# 3.6 card_entities（实体）

```sql
CREATE TABLE card_entities (
    id          UUID PRIMARY KEY,
    card_id     UUID REFERENCES cards(id) ON DELETE CASCADE,

    entity_type VARCHAR(50),
    name        TEXT,

    created_at  TIMESTAMP DEFAULT NOW()
);
```

---

# 3.7 card_relations（关系）

```sql
CREATE TABLE card_relations (
    id              UUID PRIMARY KEY,
    card_id         UUID REFERENCES cards(id) ON DELETE CASCADE,
    related_card_id UUID REFERENCES cards(id),

    relation_type   VARCHAR(50), -- related/reference/mention/parent

    created_at      TIMESTAMP DEFAULT NOW()
);
```

---

# 四、对话系统相关表

---

# 4.1 conversations

```sql
CREATE TABLE conversations (
    id              UUID PRIMARY KEY,
    user_id         UUID,

    current_state   VARCHAR(50),
    current_card_id UUID,

    context         JSONB, -- 存储 state / missing_fields

    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW()
);
```

---

# 4.2 messages

```sql
CREATE TABLE messages (
    id              UUID PRIMARY KEY,
    conversation_id UUID REFERENCES conversations(id),

    role            VARCHAR(20), -- user / assistant / system
    content         JSONB,

    created_at      TIMESTAMP DEFAULT NOW()
);
```

---

## 支持：

```text
对话回放
AI调试
上下文恢复
```

# 五、AI / 向量能力

---

# 5.1 card_embeddings

```sql
CREATE TABLE card_embeddings (
    card_id    UUID PRIMARY KEY REFERENCES cards(id),
    embedding  VECTOR(1536) -- 使用 pgvector
);
```

---

## 向量来源

```text
title + summary + content
```

---

## 用途

```text
语义搜索
相似卡片推荐
RAG
```

# 六、索引设计（关键）

---

## 6.1 cards 索引

```sql
CREATE INDEX idx_cards_user ON cards(user_id);
CREATE INDEX idx_cards_type ON cards(type);
CREATE INDEX idx_cards_status ON cards(status);
CREATE INDEX idx_cards_created_at ON cards(created_at DESC);
```

---

## 6.2 标签索引

```sql
CREATE INDEX idx_tags_name ON tags(name);
```

---

## 6.3 实体索引

```sql
CREATE INDEX idx_entities_name ON card_entities(name);
```

---

## 6.4 向量索引

```sql
CREATE INDEX idx_embedding ON card_embeddings USING ivfflat (embedding vector_cosine_ops);
```
