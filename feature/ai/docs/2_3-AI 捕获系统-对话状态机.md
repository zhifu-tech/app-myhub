# AI 捕获系统-对话状态机（以实现为准）

本文档对齐当前代码实现：

- `feature/ai/.../state/StateMachine.kt`
- `feature/ai/.../state/StateGuard.kt`
- `feature/ai/.../ConversationEngine.kt`

## 1. 状态定义

- `IDLE`：初始态，等待用户发起捕获。
- `INTENT_DETECT`：已接收用户输入，执行意图识别/草稿生成。
- `INFO_COLLECT`：草稿字段未补齐，按缺失字段引导补全。
- `CARD_REVIEW`：草稿可审查态，展示预览与编辑入口。
- `MANUAL_EDIT`：聚焦单一字段的手动编辑态。
- `PUBLISH`：发布进行中。
- `COMPLETE`：发布完成态，可发起下一次捕获。

## 2. 信号定义

- `START_CAPTURE`：开始一次新的捕获流程。
- `DRAFT_COMPLETE`：草稿字段满足发布前要求。
- `DRAFT_INCOMPLETE`：草稿仍有缺失字段。
- `REQUEST_REVIEW`：请求回到审查态。
- `REQUEST_MANUAL_EDIT`：请求进入手动编辑态。
- `REQUEST_PUBLISH`：请求发布。
- `PUBLISH_SUCCEEDED`：发布成功。

## 3. 状态转移表

### 3.1 主路径

- `IDLE --START_CAPTURE--> INTENT_DETECT`
- `INTENT_DETECT --DRAFT_INCOMPLETE--> INFO_COLLECT`
- `INTENT_DETECT --DRAFT_COMPLETE--> CARD_REVIEW`
- `CARD_REVIEW --REQUEST_PUBLISH--> PUBLISH`
- `PUBLISH --PUBLISH_SUCCEEDED--> COMPLETE`
- `COMPLETE --START_CAPTURE--> INTENT_DETECT`

### 3.2 补全与编辑路径

- `INFO_COLLECT --DRAFT_INCOMPLETE--> INFO_COLLECT`
- `INFO_COLLECT --DRAFT_COMPLETE--> CARD_REVIEW`
- `INFO_COLLECT --REQUEST_MANUAL_EDIT--> MANUAL_EDIT`

- `CARD_REVIEW --DRAFT_INCOMPLETE--> INFO_COLLECT`
- `CARD_REVIEW --DRAFT_COMPLETE--> CARD_REVIEW`
- `CARD_REVIEW --REQUEST_MANUAL_EDIT--> MANUAL_EDIT`

- `MANUAL_EDIT --DRAFT_INCOMPLETE--> INFO_COLLECT`
- `MANUAL_EDIT --DRAFT_COMPLETE--> CARD_REVIEW`
- `MANUAL_EDIT --REQUEST_REVIEW--> CARD_REVIEW`
- `MANUAL_EDIT --REQUEST_MANUAL_EDIT--> MANUAL_EDIT`
- `MANUAL_EDIT --REQUEST_PUBLISH--> PUBLISH`

## 4. 设计约束

- 所有状态变更必须通过 `StateMachine.transition(...)` 完成。
- `ConversationEngine` 不直接手写状态常量跳转。
- `StateGuard` 负责输入与动作可用性，动作判定分两层：
    - 静态动作：基于状态白名单。
    - 动态动作：解析带 payload 的动作（如 `tag:*`、`remove_media:*` 等）。

## 5. 与 UI/交互的对齐规则

- `CARD_REVIEW`：展示预览、字段编辑入口、卡片操作入口。
- `MANUAL_EDIT`：只展示当前焦点字段编辑器 + 回到审查快捷操作。
- 字段更新后统一用 `DRAFT_COMPLETE / DRAFT_INCOMPLETE` 驱动状态推进，不做旁路跳转。

## 6. 当前已落地的边界

- `IDLE` 不支持直接跳转 `INFO_COLLECT` 或 `CARD_REVIEW`。
- `PUBLISH` 为发布过程态，不承载字段编辑行为。
- `COMPLETE` 仅保留 `NEW_CAPTURE` 类动作入口。
