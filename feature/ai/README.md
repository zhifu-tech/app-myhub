# Feature AI Module

这个模块用于**规范**和**实现** MyHub 应用的 AI Capture 基础设施，为各业务模块**提供统一的草稿编排、媒体处理和 AI 推理交互能力**。

它负责把文本、图片、视频和推理结果整理成可复核、可编辑、可发布的草稿，并支持本地恢复和多端同步。

## 功能范围

- 聊天式消息流与推理过程展示
- 媒体选择、上传、生成和恢复
- 草稿预览、发布与本地自动保存
- 多语言资源与窄屏 / 宽屏自适应
