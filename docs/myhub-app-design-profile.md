# Profile 我的

## 1. 入口

> **Q：入口在哪里？应该从哪里进入？**
>
> A：依据不同导航模式，展示在不同位置

| 导航模式   | 入口位置              |
| ---------- | --------------------- |
| 底部导航   | 最后一个 Tab「我的」  |
| 侧边栏导航 | 最后一个 Item「我的」 |

---

## 2. 内容

> **Q：应该展示什么东西？**
>
> A：展示与「我」相关的所有内容

### 2.1 个人资料区

| 元素     | 说明                   |
| -------- | ---------------------- |
| 头像     | 用户头像，支持点击更换 |
| 显示名称 | 用户昵称               |
| 个性签名 | 个人格言/简介          |
| 编辑资料 | 跳转到资料编辑页面     |
| 公开主页 | 跳转到用户公开主页     |

### 2.2 功能入口

| 功能     | 说明               |
| -------- | ------------------ |
| 我的卡片 | 用户创建的所有卡片 |
| 我的收藏 | 用户收藏的内容     |
| 历史记录 | 浏览/编辑历史      |
| 数据统计 | 使用数据概览       |

### 2.3 其他

| 功能     | 说明                 |
| -------- | -------------------- |
| 设置     | 跳转到设置页面       |
| 帮助反馈 | 帮助文档与反馈入口   |
| 关于     | 版本信息、隐私政策等 |

---

## 3. 呈现方式

> **Q：页面如何呈现？**
>
> A：采用卡片式布局，模块化展示

### 3.1 布局结构

```
┌─────────────────────────────┐
│        个人资料区           │
│  ┌─────┐                    │
│  │头像 │ 昵称               │
│  └─────┘ 签名               │
│         [编辑] [公开主页]   │
├─────────────────────────────┤
│        功能入口区           │
│  ┌───┐ ┌───┐ ┌───┐ ┌───┐   │
│  │卡片│ │收藏│ │历史│ │统计│ │
│  └───┘ └───┘ └───┘ └───┘   │
├─────────────────────────────┤
│        其他功能             │
│  • 设置                     │
│  • 帮助与反馈               │
│  • 关于                     │
└─────────────────────────────┘
```

### 3.2 响应式适配

| 屏幕尺寸 | 布局调整                    |
| -------- | --------------------------- |
| 紧凑型   | 单列布局，功能入口 2x2 网格 |
| 中等     | 双列布局，功能入口横向排列  |
| 扩展型   | 左右分栏，信息更丰富展示    |
