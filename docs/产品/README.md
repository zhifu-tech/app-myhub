# MyHub · 产品文档总览（README）

本文档用于说明 **MyHub 产品相关文档的整体结构、分类方式及各文件的作用**，是进入产品文档体系的统一入口。

---

## 一、文档总体说明

MyHub 的产品文档遵循以下原则：

- **从「为什么做」到「做什么」再到「怎么演进」**
- 先定义边界，再定义功能，最后讨论扩展
- 所有文档均可独立阅读，但推荐按层级顺序理解

## 七、维护约定

- 产品方向发生变化时，**必须优先更新「产品思考与定位」文档**
