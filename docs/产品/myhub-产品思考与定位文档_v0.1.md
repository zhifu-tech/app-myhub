# MyHub 产品思考与定位文档

> **一句话定位**：MyHub 是一个“**个人与内容之间的中台**”，帮助用户把 **分散在各个平台的有价值内容**，沉淀为 **可复看、可管理、可再创作、可再传播的卡片资产**。

---

## 1. 背景与问题定义

### 1.1 现实世界的问题

当下的内容生态高度碎片化：

- 视频平台（抖音 / 快手 / YouTube / B站）
- 社交平台（朋友圈 / 小红书 / X / 微博）
- 阅读平台（书籍 / 网页 / 公众号 / Newsletter）

这些平台都在**鼓励点赞、收藏、转发**，但它们存在一个共同的问题：

> **点赞 ≠ 再利用**

一旦用户离开原平台：

- 内容就被“锁”在平台内部
- 难以跨平台统一回顾
- 无法形成系统化的知识或素材
- 复看成本极高

结果是：

- 用户“以为自己记住了”，但其实只是点了个赞
- 用户积累了大量内容，却无法再次调用

### 1.2 核心痛点总结

| 痛点      | 具体表现           |
| ------- | -------------- |
| 内容不可复用  | 必须回到原 App 才能找到 |
| 内容不可管理  | 收藏是线性的、不可分类    |
| 内容不可沉淀  | 看过即忘，无法形成长期资产  |
| 内容不可再传播 | 二次分享缺乏结构与美感    |

---

## 2. MyHub 的核心价值主张

### 2.1 MyHub 不是一个「内容平台」

MyHub **不生产内容，也不试图替代任何平台**。

它的定位是：

> **内容中台 / 个人内容资产管理系统（Personal Content Hub）**

### 2.2 MyHub 解决的根本问题

> **让“我觉得有用的内容”，从一次性消费，变成可反复使用的资产。**

MyHub 帮助用户完成 4 件关键的事：

1. **收集（Collect）**：从任何平台把内容带走
2. **结构化（Structure）**：自动生成卡片、标签、分类
3. **复看（Review）**：在合适的时间重新看见
4. **再传播（Redistribute）**：以更好的形式再次分享

---

## 3. 核心概念：卡片（Card）与卡集（Collection）

### 3.1 卡片（Card）

卡片是 MyHub 的最小内容单元。

一张卡片可以来自：

- 一个视频（链接 + 摘要 + 封面）
- 一段文字（摘抄 + 修饰）
- 一个商品（图文 + 卖点 + 视频）

卡片具备的能力：

- 自动生成摘要
- 自动打标签（主题 / 场景 / 情绪 / 用途）
- 支持用户二次编辑
- 可再次分享为链接或图片

### 3.2 卡集（Collection）

卡集是 **围绕某个目标或主题的卡片集合**。

例如：
-「一周家常菜合集」
-「这本书对我最有触动的 12 个片段」
-「英语晨读练习（Level A）」

卡集的价值在于：

- 帮助用户形成**系统化认知**
- 支持长期复习（Review）
- 具备传播价值

## 4. 典型使用场景分析

### 场景 1：跨平台做饭视频的复看

**原始状态**：

- 快手点赞一个做饭视频
- 抖音收藏一个做饭视频
- 一周后完全忘记

**MyHub 介入后**：

1. 用户一键分享到 MyHub
2. 自动生成「做饭卡片」
3. 标签：#做饭 #家常菜 #新手友好
4. 自动归入「饮食 / 做饭」卡集

**结果**：

- 想做饭 → 打开 MyHub → 看“做饭卡集”
- 清楚知道自己会做什么

---

### 场景 2：阅读摘抄与朋友圈分享

**需求本质**：

- 记录触动自己的内容
- 美化后分享
- 阅读完成后进行系统回顾

**MyHub 的价值**：

- 摘抄 → 自动排版为精致卡片
- 多条摘抄 → 自动形成「书籍卡集」
- 一键生成适合朋友圈的图片或链接

**升级点**：

> 从“我看过这本书” → “这是这本书真正改变我的地方”

---

### 场景 3：商品内容的反复传播

**核心问题**：

- 商品内容需要反复使用
- 每次重新编辑成本高

**MyHub 的解法**：

- 商品 = 一组可复用的商品卡
- 支持：文案 / 图文 / 视频
- 定期复用，一键再次分享

**本质**：

> 把“营销素材”资产化

---

### 场景 4：学生的英语学习

**问题**：

- 内容零散
- 缺乏体系

**MyHub 的能力**：

- 英语文章 → 学习卡片
- 多篇文章 → 系列卡集
- 支持反复阅读、跟读、复习

**价值提升**：

- 从“刷文章” → “构建个人学习路径”

## 5. MyHub 的核心差异化

| 维度   | 传统平台 | MyHub |
| ---- | ---- | ----- |
| 内容归属 | 平台   | 用户    |
| 内容形态 | 流    | 卡片    |
| 使用方式 | 一次性  | 可复用   |
| 管理能力 | 弱    | 强     |
| 传播方式 | 平台内  | 跨平台   |

---

## 6. MyHub 的长期愿景

> **让每个人都拥有一个属于自己的“内容资产中台”。**

未来的 MyHub：

- 是你的第二大脑（但更轻）
- 是你的内容素材库
- 是你对外表达的起点

---

## 7. 一句话总结

> **MyHub 不是让你收藏更多，而是让你真正用回你已经收藏的内容。**

## 其它

> **MyHub 这个想法是“**慢热型但非常长期**”的产品，一旦做对，很难被平台抄走。**

因为你做的是：

👉 **跨平台 + 用户资产 + 复用价值**

而不是追热点功能。
