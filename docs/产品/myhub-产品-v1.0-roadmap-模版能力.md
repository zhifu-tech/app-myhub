# v1 Roadmap：模板能力（Template Capability）

> 本章节用于说明 模板能力为何不进入 v0.1，以及 v1 如何引入，避免未来误判节奏。

---

## 1. 能力定位

`模板不是“创建工具”，而是“整理加速器”。`

在 MyHub 中，模板的目标不是帮助用户「存更多内容」，而是：

- 降低重复整理的成本
- 提高结构一致性
- 支撑长期复看与复用

因此模板能力被明确规划在 v1，而非 v0.1。

---

## 2. v1 中模板能力解决的问题

当用户进入 v1 阶段，已经出现以下行为：

- 同类型卡片反复出现（如：读书摘录 / 商品素材 / 学习笔记）
- 用户开始主动编辑卡片，而不仅是保存
- 用户对卡片内容结构有隐性预期（如“这里应该有总结”）

模板在 v1 中主要解决：

- 1. **重复输入问题** \
    同类卡片不必每次从空白开始
- 2. **结构一致性问题** \
    提升卡片之间的可比性与可复看性
- 3. **整理效率问题** \
    从“记录”升级到“系统化整理”

---

## 3. v1 模板的形态原则（非最终 UI）

- 模板 不作为强制步骤
- 模板 不阻断分享进入路径
- 模板是加速器，而非入口

可能的交互形态：

- 编辑页中「套用结构」
- 基于历史卡片的“推荐结构”
- 仅在用户多次编辑后提示
