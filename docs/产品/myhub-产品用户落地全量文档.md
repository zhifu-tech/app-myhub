# MyHub 用户落地全量文档

> 本文档用于 用户理解 / 应用市场展示 / 官网落地 / 内测冷启动，统一 MyHub 的用户表达口径。

⸻

## 一、用户落地页（核心说明页）

### **把你点过赞的内容，真正变成你的**

你一定有过这样的时刻：

- 在抖音、快手看到一个很棒的视频，点了赞
- 在书里读到一句触动你的话，随手划了线
- 收藏了很多内容，却再也没打开过

过了一段时间你才发现：

- 你记得自己“收藏过”，却完全想不起收藏了什么。

### **问题不在你，而在内容本身**

现在的 App 很擅长让你发现内容，
却几乎不关心你以后还用不用得到它。

- 点赞、收藏被锁在原平台
- 内容零散、混乱、不可整理
- 想复看时，找不到，也想不起来

**收藏，并没有帮你留下价值。**

⸻

### MyHub 是做什么的？

**MyHub 是一个帮你“把内容带走”的地方。**

你在任何平台看到有价值的内容，都可以分享到 MyHub。\
MyHub 会帮你把它变成一张 **清晰、好看、可管理的卡片**。

不是为了收藏更多，\
而是为了**以后还能再用一次**。

⸻

### 一张卡片，能帮你做什么？

每一条保存到 MyHub 的内容，都会变成一张卡片：

- 自动整理重点
- 自动生成标签
- 可以编辑、备注、再加工
- 随时查看、反复使用

你不再面对一堆“点赞记录”，\
而是面对 **真正有意义的内容集合**。

⸻

### 不只是卡片，还有「卡集」

你可以把相关的卡片放进一个卡集里，例如：

- 《这本书真正打动我的地方》
- 《我想学会的家常菜》
- 《英语晨读练习》
- 《我的商品内容素材》

当你想复习、学习、分享时，\
**打开一个卡集就够了。**

⸻

### MyHub 可以这样用

#### 🍳 做饭的时候

多个平台收藏的做饭视频\
→ 一个清晰的「做饭卡集」

#### 📖 读书的时候

摘下触动你的句子\
→ 精致卡片 → 一本书的思考合集

#### 🛍️ 分享商品的时候

商品内容整理一次\
→ 以后反复使用、反复传播

#### 📚 学习的时候\

文章、资料整理成系列卡集\
→ 学习不再零散

⸻

## 和普通收藏有什么不一样？

| 普通收藏     | MyHub             |
| ------------ | ----------------- |
| 放在原 App   | 集中在一个地方     |
| 零散、混乱   | 清晰、有结构       |
| 看过即忘     | 可以反复使用       |
| 难以分享     | 一键再传播         |

⸻

### 一句话总结

**MyHub 不是让你收藏更多，**\
**而是让你真正用回你已经收藏的内容。**

⸻

## 二、📱 App Store / 应用市场文案

### 应用名称

`MyHub`

### Slogan（短）

`把你点过赞的内容，真正变成你的`

### 应用简介（短）

`MyHub 帮你把分散在各个平台的有价值内容，整理成可复看、可管理、可再分享的卡片。`

### 应用简介（长）

你每天都会看到很多好内容。\
但真正能再次用上的，却很少。

MyHub 帮你：

- 从任何平台保存内容
- 自动整理成清晰的卡片
- 用标签和卡集统一管理
- 随时复看、再次分享

不是为了收藏更多，\
而是为了让好内容真正留下来。

适合谁使用？

- 喜欢收藏但总是忘记的人
- 爱读书、爱学习的人
- 需要反复使用内容的创作者 / 商家
