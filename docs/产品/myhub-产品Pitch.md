# MyHub — 让有价值的内容，真正变成你的资产

## 一句话介绍

**MyHub** 是一个**个人内容中台**，帮助用户将分散在各个平台的有价值内容，转化为 **可复看、可管理、可再创作、可再传播**的卡片资产。

## 我们解决什么问题？

当下内容极度丰富，但内容的价值却极度流失。

- 用户在抖音、快手、书籍、网页上不断点赞、收藏
- 但这些内容被锁在原平台
- 一旦离开平台，几乎无法再次有效使用

**点赞 ≠ 记住**  
**收藏 ≠ 再利用**

**结果是：**

> 用户拥有大量“看过的内容”，却没有任何“可调用的内容”。

## MyHub 的核心价值

**MyHub 不生产内容，也不替代任何平台。**

它的角色是：

> **连接用户与内容的中台系统**

MyHub 帮助用户完成 4 件关键的事：

1. **收集**：从任何第三方平台一键带走内容  
2. **结构化**：自动生成卡片、标签与分类  
3. **复看**：在合适的时间重新看见有价值的内容  
4. **再传播**：以更好的形式再次分享，并形成回流  

## 核心产品形态

### **卡片（Card）**

- MyHub 的最小内容单元  
- 可来自视频、文字、商品、链接  
- 自动生成摘要、封面、标签  
- 支持编辑与二次分享  

### **卡集（Collection）**

- 围绕一个主题或目标的卡片集合  
- 用于 **学习、复盘、创作、传播**  
- 具备长期复用与分享价值  

## 典型使用场景

- **生活技能**：  
  多个平台收藏的做饭视频 →「做饭卡集」→ 想做饭时一眼可见  
- **阅读与思考**：  
  摘抄书中触动的文字 → 精致卡片 → 形成整本书的思考卡集  
- **商品与内容传播**：  
  商品文案 / 图文 / 视频 → 商品卡 → 反复使用、持续传播  
- **学习成长**：  
  英语文章 → 学习卡 → 系列卡集 → 构建个人学习路径  

## 与传统平台的本质区别

| 维度       | 传统平台   | MyHub   |
| ---------- | ---------- | ------- |
| 内容归属   | 平台       | 用户    |
| 内容形态   | 信息流     | 卡片    |
| 使用方式   | 一次性消费 | 长期复用 |
| 管理能力   | 弱         | 强      |
| 传播方式   | 平台内     | 跨平台  |

## 为什么是 MyHub？

**因为它做的不是“更多内容”，而是：**

> 让你真正用回你已经看过、收藏过的内容

## 长期愿景

**让每个人都拥有一个属于自己的内容资产中台。**

MyHub 是：

- 你的轻量第二大脑  
- 你的个人内容素材库  
- 你对外表达与分享的起点  

## 一句话收尾

MyHub 不是让你收藏更多，而是让你真正用回你已经收藏的内容。
