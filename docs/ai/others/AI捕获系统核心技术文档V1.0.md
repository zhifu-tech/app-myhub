# AI 捕获系统核心技术文档

## 1️⃣ 概述

在现代 **AI 捕获系统**中，我们希望实现：

* 用户输入内容（文本、图片、语音） → 生成结构化卡片（Card）
* 自动生成标签、实体，构建知识图谱
* 支持语义搜索和相似卡片推荐

核心技术模块：

1. **LLM Tagging** – 自动生成标签、抽取实体
2. **Embedding similarity** – 用向量表示卡片和内容，实现语义搜索
3. **Vector Database** – 存储向量及元数据，支持高效相似度检索

它们紧密协作，共同支撑 AI 捕获系统的智能化。

---

## 2️⃣ LLM Tagging

**概念**：
利用大语言模型（LLM）根据用户输入或卡片内容自动生成标签、抽取实体、判断卡片类型。

**功能**：

* 自动标签生成（tags）
* 实体抽取（entities）
* 卡片类型识别（Card Type System）

**示例**：

用户输入：

```text
昨天在上海吃了一兰拉面
```

LLM tagging 输出：

```json
{
  "tags": ["美食", "拉面", "上海"],
  "entities": ["一兰拉面"],
  "type": "Entity -> Place"
}
```

**作用**：

* 减少用户手动标注
* 支持智能分类、集合、推荐
* 生成知识图谱节点属性

---

## 3️⃣ Embedding Similarity

**概念**：
将文本、图片或其他内容转换为高维向量（embedding），用向量空间计算语义相似度。

**原理**：

* 相似内容 → 向量在空间中距离靠近
* 查询向量 → 与卡片向量计算相似度

**常用计算方式**：

* 余弦相似度（Cosine Similarity）
* 欧氏距离（Euclidean Distance）
* 内积（Inner Product）

**示例**：

```text
Card 1: 一兰拉面 → Vector [0.12, 0.45, ...]
Card 2: 拉面店推荐 → Vector [0.13, 0.44, ...]
Query: 上海拉面 → Vector [0.11, 0.46, ...]
Similarity(query, Card1) = 0.98
Similarity(query, Card2) = 0.95
```

**作用**：

* 语义搜索
* 内容推荐
* 去重检测
* 相似卡片关联

---

## 4️⃣ Vector Database

**概念**：
专门存储和检索 **高维向量（embedding）** 的数据库，用于语义搜索、相似度检索和推荐系统。

**特点**：

* 存储向量 + 元数据（tags、type、entities）
* 支持快速相似度搜索（近似最近邻 ANN）
* 支持多模态向量（文本、图片、音频）
* 可扩展到亿级向量

**常见产品**：

* Pinecone（SaaS，API 简单）
* Milvus（开源，高性能）
* Weaviate（开源，多模态 + GraphQL）
* FAISS（Facebook 开源库）
* Qdrant（开源，向量 + 元数据搜索）

**作用**：

* 存储卡片 embedding
* 支持向量相似度搜索
* 提供搜索、推荐和知识图谱关联的基础

## 6️⃣ 流程总结

1. 用户输入 → **LLM tagging** 自动生成标签/实体/类型
2. 内容 → **Embedding** 转成向量
3. 向量存储 → **Vector Database**
4. 查询/推荐 → **Embedding similarity** + 标签过滤
5. 卡片更新 → Knowledge Graph & UI 展示

**效果**：

* 自动分类 & 标签
* 语义搜索 & 推荐
* 知识图谱自动关联
* 多轮对话式信息捕获
