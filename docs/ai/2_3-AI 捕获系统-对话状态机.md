# 二、术语定义（扩展）

| 术语            | 定义             |
|---------------|----------------|
| State Machine | 控制对话流程的有限状态机   |
| State         | 当前对话阶段         |
| Transition    | 状态之间的跳转        |
| Slot          | 卡片字段占位         |
| State Guard   | 状态约束机制（防止非法跳转） |
| Action        | 当前状态下允许执行的行为   |
| Context       | 当前会话上下文        |

# 五、状态定义（工程级）

---

## 5.1 IDLE

### 描述

系统等待输入。

---

### 允许输入

```text id="idle_input"
文本 / 图片 / 链接 / 语音
```

---

### 转移

```text id="idle_transition"
→ INTENT_DETECT
```

---

---

## 5.2 INTENT_DETECT

### 描述

识别用户意图（由 AI Pipeline 完成）。

---

### 输出

```json id="intent_output"
{
  intent,
  confidence
}
```

---

### 支持意图

```text id="intent_types"
create_card
edit_card
add_info
delete_info
cancel
```

---

### 转移

```text id="intent_transition"
create → DRAFT_CREATE
edit → EDIT_FIELD
```

---

---

## 5.3 DRAFT_CREATE

### 描述

生成卡片草稿（必须通过 Tool + Card Engine）。

---

### 流程

```text id="draft_flow"
LLM → extract_entities
↓
Tool: create_card
↓
Card Engine（Schema校验）
```

---

### 输出

```text id="draft_output"
card_id
draft_card
```

---

### 转移

```text id="draft_transition"
→ INFO_COLLECT
```

---

---

## 5.4 INFO_COLLECT（核心状态）

### 描述

Slot Filling 阶段（基于 Schema）。

---

## 5.4.1 Schema驱动 Slot

```json id="schema_slot"
{
  type: "place",
  required_fields: [
    "title",
    "location"
  ],
  optional_fields: [
    "image",
    "tags",
    "note"
  ]
}
```

---

## 5.4.2 核心逻辑

```text id="collect_logic"
missing_fields = detect_missing(schema, card)

if missing_fields:
    ask_next_field()
else:
    → CARD_REVIEW
```

---

## 5.4.3 行为约束（State Guard）

允许：

```text id="collect_allowed"
add_field
edit_field
skip_field
```

禁止：

```text id="collect_blocked"
publish（未完成）
```

---

## 5.4.4 单轮策略

```text id="collect_strategy"
一次只问一个字段
最多3轮
```

---

---

## 5.5 CARD_REVIEW

### 描述

展示卡片供用户确认。

---

### UI

```text id="review_ui"
Card Preview
[发布]
[修改]
```

---

### 转移

```text id="review_transition"
发布 → PUBLISH_CONFIRM
修改 → INFO_COLLECT / EDIT_FIELD
```

---

---

## 5.6 PUBLISH_CONFIRM

### 描述

二次确认发布。

---

### 行为

```text id="publish_action"
Tool: publish_card
```

---

### 转移

```text id="publish_transition"
成功 → COMPLETE
取消 → CARD_REVIEW
```

---

---

## 5.7 COMPLETE

### 描述

流程结束。

---

### 输出

```text id="complete_output"
卡片已保存
```

---

### 转移

```text id="complete_transition"
→ IDLE
```

---

# 七、异常与中断处理

---

## 7.1 CLARIFY（理解失败）

触发：

```text id="clarify_trigger"
低置信度 / 无法解析
```

---

输出：

```text id="clarify_output"
提供选项（按钮）
```

---

## 7.2 INTERRUPT（用户打断）

示例：

```text id="interrupt_case"
COLLECT_IMAGE → 用户改标题
```

---

处理：

```text id="interrupt_handling"
切换 intent → EDIT_FIELD
```

---

## 7.3 FAILSAFE（系统失败）

必须增加：

```text id="failsafe"
AI失败
Tool失败
DB失败
```

---

策略：

```text id="failsafe_strategy"
重试 / 降级 / 人工确认
```
