# AI 捕获系统完整架构

## 一、文档信息

### 1.1 基本信息

* 版本：V1.1
* 类型：AI 捕获系统架构设计文档（Production级）
* 适用对象：产品经理 / 架构师 / 前端 / 后端 / AI工程师

### 1.2 文档目标

```text
构建可扩展、可维护、可上线的 AI 对话式捕获系统
```

* 支持高并发
* AI与业务解耦
* 支持多模态输入
* 支持Tool驱动的Agent架构

## 二、术语定义

| 术语            | 定义                 |
|---------------|--------------------|
| Capture       | 将输入内容转化为结构化信息      |
| Card          | 系统标准信息单元（结构化载体）    |
| Draft         | 发布前可编辑状态           |
| Tool          | 模型触发的系统能力接口        |
| State Machine | 控制对话流程的状态机制        |
| Slot          | 卡片字段占位（title、tag等） |
| Conversation  | 用户与系统的交互上下文        |

---

## 三、系统分层架构

### 3.1 六层架构模型

```text
Client Layer
      ↓
API Gateway
      ↓
Conversation Engine（State Machine + Context + Slot）
      ↓
AI Agent Layer（LLM Agent + Tool Planner）
      ↓
Card Engine（Create / Update / Publish）
      ↓
Storage Layer（Primary DB + Vector DB + File Storage）
```

### 3.2 核心原则

* 分层解耦：UI / 对话管理 / AI / Tool / Card / Storage
* AI只负责理解与决策，不直接修改数据
* 数据结构Schema驱动，确保数据一致性
* 状态机驱动流程，保证对话可控
* 支持多模态扩展（文本 / 图片 / 链接等）

## 六、Conversation Engine（对话管理核心）

### 6.1 模块结构

```text
Conversation Engine
    ├── State Machine
    ├── Context Manager
    ├── Slot Manager（Schema驱动）
    └── Action Planner
```

### 6.2 状态机

```text
IDLE → INTENT → DRAFT → COLLECT → REVIEW → PUBLISH
```

* 每个状态定义允许动作、禁止动作、出口条件
* 状态守卫（State Guard）拦截非法操作

### 6.3 Context Manager

```json
{
  "conversation_id": "123",
  "state": "COLLECT",
  "card_id": "card_123",
  "history": [
    ...
  ],
  "missing_fields": [
    "image",
    "note"
  ]
}
```

### 6.4 Slot Manager（Schema驱动）

* 根据Card Type动态生成Slot
* 自动检测缺失字段

```json
{
  "type": "restaurant",
  "required_fields": [
    "title",
    "location"
  ],
  "optional_fields": [
    "image",
    "tags"
  ]
}
```

### 6.5 Action Planner

* 决策下一步动作：

```text
ask_question
suggest_tag
show_review
publish_card
```

## 七、AI Agent Layer（LLM + Tool调度）

### 7.1 核心职责

* 理解用户意图（Intent）
* 抽取实体（Entity Extraction）
* 决策Tool调用（Tool Planner）
* 生成用户可见响应

### 7.2 Prompt层次

```text
System Prompt → 角色规则、不可修改数据
Task Prompt → 当前对话上下文
Tool Prompt → 可用工具说明与参数
```

### 7.3 Tool Layer（AI可调用能力）

至少八个工具：

```text
create_card
update_card
suggest_tags
analyze_content
analyze_image
summarize_content
extract_entities
publish_card
search_cards
```

### 7.4 Agent决策流程

```text
User Input
 ↓
LLM Reasoning
 ↓
Tool Selection
 ↓
Tool Execution
 ↓
Update Context
 ↓
Generate Response
```

### 7.5 多工具链

```text
收藏网页 → analyze_link → extract_entities → summarize_content → create_card
```

### 7.6 上下文管理

```json
{
  "conversation_id": "",
  "state": "",
  "card_id": "",
  "last_action": "",
  "missing_fields": []
}
```

存储：Redis（缓存会话，支持多轮对话）
